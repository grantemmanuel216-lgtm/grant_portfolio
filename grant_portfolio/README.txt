# Grant Emmanuel — Personal Portfolio

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — black, blue and gold design; responsive layouts
- `script.js` — mobile menu, reveal-on-scroll, footer year and back-to-top button
- `assets/` — add your own images here

## Add your images
Put your images in the `assets` folder and use these exact names:

1. `profile.jpg` — your profile photo (top-left side of the hero section)
2. `javascript-certificate.jpg` — JavaScript certificate
3. `web-development-certificate.jpg` — Web Development certificate

For the other images, the timeline currently uses clean placeholders. You can replace each
`<div class="media-placeholder">...</div>` in `index.html` with an `<img>` element when
you have your WAAW photo and PPSSPP screenshots.

## Personal details to update
- Search for `your.email@example.com` in `index.html` and replace it with your public email.
- Confirm the exact official name of the WAAW competition and the award wording before publishing.
- If you have the competition year or certificate dates wrong, edit the timeline text.
- Add real project links only when you have projects you can show.

## Run it
Keep the three files in the same folder. Open `index.html` in a browser, or place the folder
inside your XAMPP `htdocs` directory and open it through localhost.

No frameworks or external JavaScript libraries are required. Google Fonts are loaded online;
the page still works with fallback fonts if you are offline.
